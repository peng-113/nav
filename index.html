添加网站

连接 GitHub 仓库

配置后，增删网站可直接从页面保存，无需手动上传文件。只需配置一次，信息存在本地浏览器中。

1
前往 GitHub → Settings → Personal access tokens，点 Generate new token (classic)
2
Note 随便填，Expiration 选 No expiration，勾选 repo 权限，点底部 Generate
3
复制生成的 Token（只显示一次），填入下方
就是你放 index.html 的那个仓库名
Token 仅保存在你的浏览器本地，不会上传到任何服务器
